# cotizatech (aplicación)

Aquí viven el **frontend** (`src/`, React + Vite) y el **backend** (`server/`, Express + SQLite) de CotizaTech.

- Instrucciones completas, usuarios de prueba y arquitectura: ver el [README principal](../README.md).
- Documentación de la API, patrones GoF y pruebas: ver [server/README.md](server/README.md).

```bash
npm install
npm run db:reset   # crea la base con datos de ejemplo
npm run api:dev    # API en http://localhost:3000
npm run dev        # en otra terminal: front en http://localhost:5173
```
